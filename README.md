# Private OpenSpec

Spec-driven development skills for Codex, Claude Code, Pi, Cursor, Devin,
OpenCode, Warp, DSH, and Grok.

- [Install in your projects](docs/installation.md)
- [Development workflow and independent reviews](docs/workflow.md)

Proposals and specs describe business outcomes and observable behavior.
Requirements are reviewed before implementation. Codex and Claude Code review
each other's work after implementation. Verification and current review evidence
are required before archive. Unresolved decisions stay in `openspec/decisions.md`.
Small changes use the `small-change` schema with the same review checks.

This is a private fork. The upstream website, public release automation,
community material, telemetry, self-updaters, and planning history have been removed. The original
[MIT license](LICENSE) is retained.
